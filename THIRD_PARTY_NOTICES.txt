Ideas and file formats (no code taken)
    Mapsmith reads and writes Valve's file formats (VMF, VMT, VTF, VPK, MDL/VVD/VTX/PHY,
    PCF, BSP, SMD, QC) after the public descriptions: the Source SDK 2013 headers (studio.h,
    optimize.h, bspfile.h, phyfile.h), the Valve Developer Community wiki and the format
    documentation of xiph.org (FLAC) and Microsoft (ADPCM WAV). The lighting preview uses
    VRAD's published formulas. Behaviour and look follow Valve's Source 2 Hammer and
    Hammer++ (see README); "Export for editing" does what Crowbar's decompile does,
    written anew.
